# 判定与严重度（verdicts-and-severity）

## 1. 四种判定（verdict）

| 判定 | 含义 | 典型证据 |
|---|---|---|
| `supported` | 所引来源明确报告了论断核心内容；无数值、否定或引号冲突 | 高词项覆盖；数值可在来源中找到；无相反表述 |
| `partially_supported` | 来源主题相关，但数值、范围或强度未被完整报告 | 覆盖介于 0.28–0.55；或来源未报告某个数值 |
| `unsupported` | 来源不支持该论断：覆盖过低、数值冲突、否定相反或结论超出引文 | 同单位不同值；`all/every` 式绝对化；覆盖 < 0.28 |
| `unverifiable` | 找不到可解析来源、来源无正文/摘要、PDF 不可抽取或标识符缺失 | 标记无对应条目；来源只有标题；扫描件无文本层 |

判定不是“引用是否存在”的结论。引用存在但**不支持结论**时，应判 `partially_supported` 或 `unsupported`，不能因为“有这条文献”就算通过。

## 2. 严重度（severity）

| 级别 | 定义 | 处置要求 |
|---|---|---|
| `high` | 事实错误或高风险：数值冲突、否定相反、来源已撤稿、结论明显超出引文范围 | 必须修改后才能进入发表流程 |
| `medium` | 证据不足或需人工确认：部分支持、来源未报告关键数值、引用无法定位、缺关键标识符 | 复核并留下处置记录 |
| `low` | 规范/元数据问题：缺 venue、年份、DOI 形状异常 | 不改变结论，但影响可回查性 |
| `info` | 通过项或正向记录 | 保留为可复核的检查记录 |

默认映射（`assets/policy.json` 的 `verdict_severity`）：

| verdict | severity |
|---|---|
| supported | info |
| partially_supported | medium |
| unsupported | high |
| unverifiable | medium |

来源级问题单独给严重度：撤稿 `high`；预印本 `medium`；缺标识符/venue/年份 `low`。因此同一论断可能同时有“判定 finding”和“可靠性 finding”，二者都保留。

## 3. 决策顺序

1. 无来源或来源无文本 → `unverifiable`。
2. 计算词项覆盖，得到初始判定。
3. 数值冲突 → `unsupported`；数值缺失 → 至多 `partially_supported`。
4. 否定方向相反 → `unsupported`。
5. 引号不匹配 → 至多 `partially_supported`。
6. 绝对化措辞 + 未接近完整覆盖 → `unsupported`。
7. 词项过少 → `unverifiable`（不做硬判）。

后置检查可以下调判定，不会把 `unsupported` 上调为 `supported`。

## 4. 修改建议模板

| 情形 | 建议 |
|---|---|
| supported | 无需修改；可补充分节/页码提升可定位性 |
| 数值冲突 | 以来源原文为准更正数值，或更换能支持该数值的来源 |
| 数值缺失 | 核对来源全文或补充能报告该数值的引用；否则改为定性表述并标待复核 |
| 否定冲突 | 按来源原文改写结论，或更换支持该方向的来源 |
| 引号不匹配 | 改为来源原文的连续片段，或删除引号改为转述 |
| 结论超范围 | 删除/替换引用，或把结论收窄到来源实际覆盖的范围 |
| 撤稿 | 移除该引用或明确讨论撤稿原因，改用未撤稿证据 |
| unverifiable | 补齐文献条目或标识符后重新核验；补齐前不得补写来源 |

## 5. 何时必须写 `unverifiable`

- 标记在提供的参考文献/来源中找不到；
- 来源只有标题或元数据，没有摘要/正文可比较；
- PDF 无文本层或抽取失败；
- 论断有效词项过少，覆盖比例不可靠；
- 只有“某处应该有一篇文献”的线索，没有实际条目。

`unverifiable` 不是失败，而是诚实结论：结果中同时给出 `reason`、`resolution` 与 `needs_recheck=true`。
